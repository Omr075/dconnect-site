Documentação

Guia oficial para utilização das nossas APIs.

Autenticação

Todas as requests devem incluir uma API Key válida. 

Authorization: Bearer SUA_API_KEY

Endpoint Base

https://api.mozapi.com

Exemplo de Request

fetch("https://api.mozapi.com/ping", {
  headers: {
    Authorization: "Bearer SUA_API_KEY"
  }
})
.then(res => res.json())
.then(console.log)
