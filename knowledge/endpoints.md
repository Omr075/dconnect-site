# Endpoints

/api/ai/chat
Chat com Inteligência Artificial, teste ela no playground, caso queira usar um modelo específico procure o modelo de seguida integre no teu projecto, !Lembre-se Existem modelos pagos.

/api/music/search
Pesquisa informações de músicas, e devolve informações detalhadas sobre a músicas.

/api/music/song
Obtém informações de uma música e uma prévia, aconselhado para quem quer testar se a música é a mesma, trás uma prévia dw 29s.

/api/video
Pesquisa vídeos, e retorna os melhores resultados.

/api/lyrics
Obtém letras de músicas.

Todos os endpoints necessitam de uma API Key válida.
Existem ainda modelos nao implementados... Eles serão informados assim que implementados.
