# FAQ

Como criar conta?

Clique em "Começar agora" e de seguida crie a sua conta informando seus dados.
ou até Através da página de registo.

Como obter uma API Key?

Após criar uma conta, no dashboard você consegue encontrar a sua api algo como moz_sk_xxxxxxxxxxx.Guarde com responsabilidade.


Onde vejo as requisições?

No Dashboard, vá em estatísticas lá você encontra suas requisi:
ções detalhadas, ou apartir do dashboard você consegue ver.

Como testar endpoints?

No Playground, como chegar lá? estás no dashboard desce a tela e vá até onde vem o seguinte: testwr chave e endpoints clique isso vai até o playground.


Como copiar a API Key?

Existe um botão próprio no Dashboard.

Como alterar o meu nome? ou os meus dados pessoais?

No dashboard, vá em configurações ou definições e lá você encontra todas opcões.
